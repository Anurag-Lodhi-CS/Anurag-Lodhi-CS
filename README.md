## 🔍 AI Evaluation Samples

### Sample 1 — C++ Array Logic Error

**Prompt:** Write a C++ program to find the largest
element in an array.

**AI Output (WRONG ❌):**
```cpp
int max = 0;
for(int i = 0; i < n; i++){
    if(arr[i] > max) max = arr[i];
}
```

**My Correction (✅):**
```cpp
int max = arr[0];
for(int i = 1; i < n; i++){
    if(arr[i] > max) max = arr[i];
}
```

**Why:** Initializing with 0 fails when all elements are
negative. Input {-5, -3, -8} returns 0 which is not
even in the array.

---

### Sample 2 — Math Reasoning Error

**Prompt:** Solve: integral of x² dx

**AI Output (WRONG ❌):** x²/2 + C

**My Correction (✅):** x³/3 + C

**Why:** AI applied the derivative rule instead of the
integration rule. Correct rule: ∫xⁿ dx = xⁿ⁺¹/(n+1) + C
